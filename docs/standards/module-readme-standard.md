# Module README Standard

Each reusable module should have a module README when the module contains
multiple scripts, non-obvious behavior, or test assets.

## Purpose

A module README should help a contributor understand:

- what the module does
- which scripts exist
- supported platforms
- important variables
- how to validate the module

## Recommended Structure

Use this order:

1. title
2. purpose
3. supported platforms
4. module contents
5. variables and defaults
6. script inventory
7. usage examples
8. testing notes
9. related files

## Scope Rule

Module READMEs document module behavior. Platform-wide rules belong in
`docs/standards/`.

## Template

Start from `docs/templates/README.module.md`.
