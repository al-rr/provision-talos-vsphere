# talos-dev

This project was generated by:

```bash
cluster.sh create-project --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
```

## Quick Flow

1. Fill values in `vars.sh`.
2. Optionally create `vars.local.sh` from `vars.local.example.sh`.
3. Refresh Talos images from schematics:

```bash
cluster.sh refresh-schematics --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev --talos-version=v1.12.4
```

4. Execute:

```bash
cluster.sh generate --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
cluster.sh provision --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
cluster.sh prepare-bootstrap --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
cluster.sh apply-config --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
cluster.sh bootstrap --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
cluster.sh sync-access --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
cluster.sh apply-cluster-config --project-dir=/home/vagrant/talos-vsphere-lab/overlays/lab/talos/talos-dev
```
