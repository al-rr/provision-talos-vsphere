# talos-dev

This project was generated by:

```bash
export PROJECT_DIR="$(pwd)/overlays/lab/talos/talos-dev"
cluster.sh create-project --project-dir="$PROJECT_DIR"
```

## Quick Flow

1. Fill values in `vars.sh`.
2. Optionally create `vars.local.sh` from `vars.local.example.sh`.
3. (Optional) Refresh Talos images from schematics if you changed schematic files:

```bash
cluster.sh refresh-schematics --project-dir="$PROJECT_DIR" --talos-version=v1.12.4
```

4. Execute:

```bash
cluster.sh generate --project-dir="$PROJECT_DIR"
cluster.sh provision --project-dir="$PROJECT_DIR"
cluster.sh prepare-bootstrap --project-dir="$PROJECT_DIR"
cluster.sh apply-config --project-dir="$PROJECT_DIR"
cluster.sh bootstrap --project-dir="$PROJECT_DIR"
cluster.sh sync-access --project-dir="$PROJECT_DIR"
cluster.sh apply-post-bootstrap --project-dir="$PROJECT_DIR"
```
